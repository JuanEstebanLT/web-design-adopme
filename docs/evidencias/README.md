## Guion sugerido para video (máximo 5 minutos)

1. **0:00–0:35 · Problema y propuesta de valor.** Presentar Adopme, actores y alcance.
2. **0:35–1:20 · Prototipo.** Mostrar Inicio, Catálogo y Detalle en Stitch.
3. **1:20–2:15 · Arquitectura.** Explicar React/Vite, Supabase, Prisma de servidor y Vercel.
4. **2:15–3:05 · Modelo y API.** Recorrer las cuatro entidades y los contratos principales.
5. **3:05–4:10 · Repositorio ejecutable.** Mostrar navegación, estructura y validaciones.
6. **4:10–4:45 · Gestión.** Enseñar issues, milestones, Project y flujo de pull requests.
7. **4:45–5:00 · Estado y próximos pasos.** Distinguir lo implementado de lo pendiente.

Antes de grabar, sustituir esta guía por evidencias reales y distribuir la participación de común acuerdo; no se han asignado segmentos a integrantes específicos.
